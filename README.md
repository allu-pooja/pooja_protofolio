# Pooja Sathvika — Personal Portfolio

## Run locally
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for deployment
```bash
npm run build
```

The site is built with React + Vite and is fully responsive.

### Update later
- Replace the GitHub project links with direct repository URLs.
- Add a profile photo in `public/` if desired.
- Add exact BNP Paribas internship dates when available.
